RotoDesk 0.1.10 fixes text clipboard synchronization.

- Clipboard synchronization starts enabled in every viewer session.
- Copy, cut and paste shortcuts now reach the remote desktop.
- Clipboard writes retry when Windows temporarily has the clipboard occupied.
- Pasting waits for the remote clipboard write before injecting Ctrl+V, preventing stale text from being pasted. Install 0.1.10 on both devices for this behavior.
- Clipboard shortcuts preserve held modifiers and respect the host's clipboard and keyboard permissions.

Validation: 94 client, host, GUI and protocol tests passed, including LAN connection and file transfer tests.
