# RotoDesk 0.2.0

- New name, Roto2-inspired monitor mascot and mint green visual identity.
- Bold condensed italic wordmark, updated app icons, installer, executables,
  documentation and repository references.
- Existing device IDs, unattended passwords, trusted peers, recent sessions
  and thumbnails are preserved when the previous profile is migrated.
- Windows service upgrades preserve the service profile; protocol discovery
  and authentication remain compatible with previous clients.
- An installer alias is included so previous versions can update automatically
  to RotoDesk. The alias contains the same RotoDesk installer.
- Screenshots use fictional device IDs and an isolated demonstration profile.
