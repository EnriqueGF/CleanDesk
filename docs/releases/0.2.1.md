# RotoDesk 0.2.1

Connecting to a background host now opens a password dialog when the host
requires unattended access, instead of leaving the rejection in a banner that
can be outside the visible area.

- The dialog keeps the selected device, including connections started from
  recent sessions or contacts. Enter or Connect retries with the password.
- Password input is masked; remembering access continues to store only the
  derived key. Cancel clears the entered password.
- Rejected unattended passwords reopen the dialog with an error.
- English and Spanish UI text. Host authentication and permissions are unchanged.
