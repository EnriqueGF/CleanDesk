# RotoDesk 0.2.2

- Optional automatic reconnection after a lost session. A modal shows the
  target and countdown; attempts continue indefinitely with five seconds
  between failures until the connection succeeds or the user cancels.
- Enable reconnection on Home, in General settings or in the session toolbar.
  Intentional session closure does not reconnect. A changed identity stops
  retries; a rejected password pauses them and opens the password dialog.
- Recent devices and contacts show their desktop wallpaper, refreshed during
  authenticated sessions in either direction and retained locally afterward.
  Open windows are never used for these previews.
- Wallpaper exchange requires both peers to support protocol 2.5 (RotoDesk
  0.2.2). Earlier peers still connect with a placeholder preview.
- Wallpaper data is bounded to 320 × 180 and 48 KiB and is exchanged only after
  authorization. No images are published through discovery.
