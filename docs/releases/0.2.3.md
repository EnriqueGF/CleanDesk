# RotoDesk 0.2.3

- Forward individual mouse-wheel events in their original order with clicks
  and keys, preserving rapid turns and direction changes within one frame.
- Correct wheel scaling: one physical notch now forwards one notch instead
  of 80% of its distance. Keep precision-wheel and touchpad deltas.
- Synchronize Ctrl/Shift/Alt before the wheel event, so modified scrolling
  and zoom reach the host with the right keys held. Correct horizontal direction.
- Accumulate sub-unit fractions on the Windows host rather than rounding each
  small movement away. Invalid and excessive deltas are bounded.
- Input remains on the reliable, ordered channel with existing permissions
  and wire compatibility. Update both viewer and host for the complete fix.
